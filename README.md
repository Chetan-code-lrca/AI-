## Use and contribution

- Start with the README in the project you intend to use; its setup steps are authoritative for that codebase.
- Check the repository's license and data provenance before copying, modifying, or redistributing code or datasets.
- Do not commit API keys, OAuth tokens, private datasets, or personal information.
- Treat model outputs as estimates. Review each project's evaluation method, known limitations, and intended use.
- Open issues and pull requests in the repository that owns the implementation.

This index intentionally links to public repositories only. Private projects are not listed here.
