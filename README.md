## Contribution and maintenance

- Open issues and pull requests in the repository that owns the implementation.
- Keep API credentials and private datasets out of Git.
- Prefer small, reproducible examples with automated tests.
- Treat model predictions as estimates; document data, evaluation method, and known limitations.

This index intentionally contains no duplicate application code or unused dependencies.
